# ⚔️ 网页回合RPG

一款可在浏览器中运行的回合制RPG游戏，支持存档、多人副本、丰富道具系统。

## 🎮 游戏功能

### 🗺️ 地图系统
游戏包含 **8个区域**，等级由低到高递进：

| 区域 | 解锁等级 | 主题色 | 怪物示例 |
|------|---------|--------|----------|
| 🌳 森林 | Lv.1 | 绿色 | 史莱姆、野狼、山贼 |
| 🌿 草原 | Lv.3 | 浅绿 | 毒蛇、野猪、土匪头目 |
| 🕳️ 洞穴 | Lv.5 | 紫色 | 洞穴蝙蝠、石像鬼、毒蝎 |
| 🌋 火山 | Lv.8 | 橙色 | 熔岩怪、火焰蜥蜴、火山巨魔 |
| ❄️ 冰原 | Lv.12 | 青色 | 冰霜狼、雪巨人、冰龙 |
| 🏰 暗夜城堡 | Lv.15 | 靛蓝 | 骷髅战士、黑暗骑士、吸血鬼公爵 |
| ☁️ 天空之城 | Lv.18 | 粉色 | 飞行魔像、雷电之神、天使长 |
| 👹 BOSS领域 | Lv.10 | 红色 | 暗影刺客、巨石魔像、巨龙 |

### ⚔️ 战斗系统
- **攻击**：普通攻击，消耗行动回合
- **技能**：
  - 💥 重击：1.5倍伤害，2回合冷却
  - 🛡️ 铁壁：防御+10，持续2回合
  - ⚔️ 连击：连续攻击2次，4回合冷却
- **暴击 & 闪避**：概率触发战斗特效
- **属性压制**：防御方有概率闪避攻击

### 装备系统
- ⚔️ 武器：增加攻击力和暴击率
- 🛡️ 防具：增加防御力和血量
- 💍 饰品：增加闪避率和各种属性
- 支持购买、出售、替换装备

### 道具背包系统
- 🎁 怪物掉落：击败怪物概率获得道具
- 道具类型：
  - 治疗药水：恢复30点血量
  - 高级治疗药水：恢复80点血量
  - 力量卷轴：攻击+3（战斗3回合）
  - 护盾卷轴：防御+5（战斗3回合）
  - 暴击水晶：本场战斗暴击率+15%
  - 幸运金币：下只怪物金币+50%
  - 解毒药：解除当前诅咒
  - 复活卷轴：死亡时自动复活并恢复50%血量

### 📜 任务系统
- 击败指定数量怪物
- 探索各区域
- 挑战BOSS
- 金币积累任务
- 连续击杀任务
- 世界征服任务

### 🏆 成就系统
- 区域霸主（8个地图各有专属成就）
- 屠龙者、万元户、事件达人
- 任务完成者、升级达人、世界征服者

### 🎲 随机事件
- 🎁 发现宝箱：获得金币
- 🧪 老练商人：恢复生命
- ⚠️ 陷阱：受到伤害
- ✨ 神秘祝福：获得buff
- 💀 诅咒：属性下降
- 📚 经验泉水：获得经验
- 💰 盗贼袭击：损失金币
- 🧘 修行顿悟：属性永久提升

### 💾 存档系统
- 💾 3个手动存档位
- ⏱️ 每30秒自动保存
- 支持存档/读档功能

### ⚙️ 游戏设置
- 🎵 音效开关
- ⚡ 战斗速度调节（慢速/正常/快速/极快）

### 📖 怪物图鉴
- 📖 记录已发现的怪物
- 显示击杀次数和首次击败时间
- 未发现怪物显示为???状态

## 🛠️ 技术栈

- 纯原生 JavaScript（ES5语法）
- 无外部依赖
- LocalStorage 数据持久化
- 响应式设计，支持移动端

## 📱 运行方式

直接用浏览器打开 `index.html` 即可运行游戏。
