# 🧧 修仙问道

一款可在浏览器中运行的修仙文字放置游戏，包含境界突破、渡劫系统、副本挑战、宗门洞府等丰富玩法。

## 🎮 游戏功能

### 🗺️ 地图系统
游戏包含 **9个区域**，境界由低到高递进：

| 区域 | 境界 | 主题色 | 怪物示例 |
|------|------|--------|----------|
| 🌳 青云山脉 | 炼气期 | 绿色 | 灵兔、野狼妖、山魈 |
| 🌿 万兽谷 | 筑基期 | 浅绿 | 灵豹、巨蟒、虎妖 |
| 🕳️ 幽冥洞窟 | 金丹期 | 紫色 | 幽魂、骷髅妖、冥将 |
| 🌋 赤焰火山 | 元婴期 | 橙色 | 火焰精灵、熔岩巨兽、炎帝 |
| ❄️ 极寒冰原 | 化神期 | 青色 | 冰魔、雪怪、冰凤凰 |
| 🏰 魔域 | 炼虚期 | 靛蓝 | 恶魔、堕天使、魔皇 |
| ☁️ 仙界遗迹 | 合体期 | 粉色 | 仙人残魂、天兵天将、仙兽 |
| 🌌 天劫之地 | 大乘期 | 紫色 | 天劫化身、仙人残魂 |
| 👹 真龙领域 | 渡劫期 | 红色 | 真龙 |

### 🧘 境界修炼系统
- **境界体系**：炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 炼虚期 → 合体期 → 大乘期 → 渡劫期
- **每境9层**：每层需要积累足够的修为才能突破
- **瓶颈突破**：第3、6、9层需要突破瓶颈，成功率随次数降低
- **渡劫系统**：每次大境界突破需要渡天劫
  - 筑基天劫、金丹雷劫、元婴风劫...
  - 渡劫成功获得大量修为加成
  - 渡劫失败会损失部分修为和生机

### ⚔️ 斗法系统
- **普通攻击**：基础攻击方式
- **神通技能**：
  - 🔥 火球术：1.5倍伤害，2回合冷却
  - 🛡️ 金刚罩：防御+10，持续2回合
  - ⚔️ 御剑诀：连攻2次，4回合冷却
- **暴击 & 闪避**：概率触发战斗特效
- **属性压制**：防御方有概率闪避攻击

### 🐾 灵宠系统
- **灵宠召唤**：单抽/十连抽
- **稀有度**：普通(60%)、稀有(25%)、史诗(12%)、传说(3%)
- **灵宠列表**：
  - 普通：🐕 灵狼、🟢 史莱姆、🐦 灵鸟
  - 稀有：🔥 火精灵、❄️ 冰精灵、🦊 灵狐
  - 史诗：🐈‍⬛ 暗影豹、🧙 灵龟
  - 传说：🐲 幼龙、🦅 凤凰
- **灵宠加成**：攻击、防御、血量加入角色属性

### 🌳 功法神通系统
- **获取方式**：每次升级获得1点技能点
- **三系神通**：
  - ⚔️ 攻击系：三重打击、处决、狂暴
  - 🛡️ 防御系：盾墙、反击、堡垒
  - ⚡ 辅助系：疾风、喘息、涅盘
- **神通类型**：主动神通、被动神通

### 🔨 炼器系统
- **强化规则**：每级消耗灵石，成功率逐级下降
- **强化效果**：
  - 武器强化：攻击+2/级
  - 防具强化：防御+2、血量+10/级
  - 饰品强化：随机属性+2/级
- **失败惩罚**：30%概率降级

### ⚗️ 炼丹系统
- **炼制丹药**：消耗灵草炼制各种丹药
- **常用丹药**：
  - 气血丹：恢复生机
  - 筑基丹：辅助筑基突破
  - 金元丹：辅助金丹突破
  - 悟道茶：临时提升悟道点

### 🏛️ 宗门系统
- **加入宗门**：可选择加入不同宗门
- **宗门任务**：每日任务获得贡献值
- **宗门贡献**：提升宗门地位
- **宗门职位**：外门弟子 → 内门弟子 → 核心弟子 → 长老 → 宗主

### 🏠 洞府系统
- **灵田**：每小时产出灵石
- **炼丹房**：提升炼丹成功率
- **炼器室**：提升炼器成功率
- **灵池**：提升打坐效率和生机恢复

### 🤝 社交系统
- **AI玩家**：随机生成的修仙者
- **师徒系统**：拜师/收徒，获得修炼加成
- **道侣系统**：寻找道侣，双修获得巨额修为加成

### 📜 剧情系统
- **8个章节**，根据境界自动解锁：
  - 初入仙途（炼气期）
  - 初窥门径（炼气3层）
  - 筑基之境（筑基期）
  - 宗门之邀（筑基期）
  - 洞府之便（金丹期）
  - 仙缘之遇（金丹期）
  - 金丹大道（元婴期）
  - 渡劫飞升（大乘期）

### 🏰 副本系统
- **5个副本**，难度递增：
  | 副本 | 难度 | 层数 | 推荐境界 | 通关奖励 |
  |------|------|------|----------|----------|
  | 青云秘窟 | 简单 | 5层 | 炼气3层 | 500灵石+攻击卷轴 |
  | 万兽巢穴 | 中等 | 8层 | 筑基6层 | 1500灵石+防御卷轴 |
  | 幽冥深渊 | 困难 | 10层 | 金丹9层 | 3000灵石+暴击水晶 |
  | 火山熔岩 | 困难 | 12层 | 元婴15层 | 8000灵石+灵石袋 |
  | 仙劫试炼 | 极难 | 15层 | 大乘25层 | 20000灵石+仙核 |

### 💡 新手引导
- **7个引导步骤**，自动触发：
  1. 欢迎来到修仙世界（游戏开始）
  2. 战斗系统（首次战斗后）
  3. 境界突破（达到第3层）
  4. 装备强化（购买装备后）
  5. 宗门系统（加入宗门后）
  6. 洞府系统（建设洞府后）
  7. 师徒道侣（达到金丹期）

### 🗡️ 法宝装备
- **武器**：增加攻击力和暴击率
- **防具**：增加防御力和血量
- **饰品**：增加闪避率和各种属性
- **法宝品质**：法器 → 灵器 → 法宝 → 古宝

### 📖 储物袋系统
- **怪物掉落**：击败怪物概率获得道具
- **道具类型**：
  - 气血丹：恢复生机
  - 攻击卷轴：战斗攻击+3
  - 防御卷轴：战斗防御+5
  - 暴击水晶：本场战斗暴击率+15%
  - 灵石袋：获得大量灵石

### 📜 任务系统
- 击败指定数量妖兽
- 探索各区域
- 挑战BOSS
- 灵石积累任务
- 连续击杀任务
- 世界征服任务

### 🏆 成就系统
- 区域霸主（9个地图各有专属成就）
- 屠龙者、富甲一方、事件达人
- 任务完成者、修炼达人、世界征服者

### 🎲 奇遇系统
- 🎁 发现宝箱：获得灵石
- ⚠️ 陷阱：受到伤害
- ✨ 神秘祝福：获得buff
- 💀 诅咒：属性下降
- 📚 灵泉：获得修为
- 🧘 顿悟：属性永久提升

### 💾 存档系统
- 💾 3个手动存档位
- ⏱️ 每30秒自动保存
- 支持存档/读档功能

### ⚙️ 游戏设置
- 🎵 音效开关
- ⚡ 战斗速度调节（慢速/正常/快速/极快）

### 📖 妖兽图鉴
- 📖 记录已发现的妖兽
- 显示击杀次数和首次击败时间
- 未发现妖兽显示为???状态

## 🛠️ 技术栈

- 纯原生 JavaScript（ES5语法）
- 无外部依赖
- LocalStorage 数据持久化
- 响应式设计，支持移动端

## 📱 运行方式

直接用浏览器打开 `rpg.html` 即可运行游戏。
