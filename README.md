# GitHub Pages for RPG Game

This is a simple turn-based RPG game that can be played in any browser.

## How to Play

Simply open `index.html` in your web browser, or visit the GitHub Pages URL if hosted.

## Features

- Battle system with multiple monsters
- Equipment and inventory system
- Quest and achievement system
- Random events
- Save/Load functionality
- Monster compendium

## Development

This project uses vanilla JavaScript with no external dependencies.
